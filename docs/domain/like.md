# いいね

用語は [ユビキタス言語](README.md#ユビキタス言語) に従う。

## いいねが必要なもの

次のものは、いいねをもらうことで認められる。

| いいねが必要なもの | 出せる家族 |
|---|---|
| 相談 | 家族の誰でも |
| 今月のやりくりを変えるおねがい | おさいふ係 |
| どきどきラインを変えるおねがい | おさいふ係 |
| おさいふからだすおねがい | おさいふ係 |
| おさいふ係にする・外すおねがい | おさいふ係 |
| おうちの時間を変えるおねがい | おさいふ係 |
| おうちのお金を変えるおねがい | おさいふ係 |

## いいねする人

いいねする人は、相談やおねがいを出した家族によって決まる。

| 出した家族 | いいねする人 |
|---|---|
| おさいふ係ではない家族 | おさいふ係 |
| おさいふ係（ほかにもおさいふ係がいる） | 出した家族以外のおさいふ係 |
| 唯一のおさいふ係 | 自分自身（じぶんでいいね） |

- 相談やおねがいを出した家族は、自分の相談やおねがいにいいねも見送りもできない。ただし、唯一のおさいふ係のじぶんでいいねは除く。
- 同じおさいふ係が、同じ相談やおねがいに 2 回以上いいねすることはできない。
- いいねする人は、相談やおねがいを出した時点のおさいふ係で決める。あとからおさいふ係が増えたり減ったりしても変わらない。

## 必要ないいねの数

### おねがい

おねがいに必要ないいねは、1 つである。

### 相談

相談に必要ないいねは、ふだんは 1 つである。次のどちらか、または両方に当てはまるときは、2 つになる。

- 相談した金額が、どきどきラインを超えている。
- 相談した金額が、やりくりの残りを超えている。

ただし、いいねする人が 1 人しかいないときは、どちらに当てはまっても 1 つでよい。唯一のおさいふ係の相談は、じぶんでいいねで認められる。

「超えている」は、相談した金額がどきどきラインややりくりの残りより大きいことを指す。ちょうど同じ金額は、超えていないものとする。

どきどきラインは、0 円以上の金額にする。0 円にすると、すべての相談にいいねが 2 つ必要になる。

### 判断するとき

- どきどきラインを超えているかは、相談を出したときに判断する。
- やりくりの残りを超えているかは、1 つ目のいいねのときに判断する。
- 必要ないいねの数は、1 つ目のいいねのときに決まり、あとから変わらない。2 つ目のいいねのときに、やりくりの残りを計算し直すことはしない。
- いいねが 2 つ必要になった理由（どきどきライン、やりくりの残り、またはその両方）は、家族に見えるように記録する。

### 早いもの勝ち

必要ないいねがそろった時点で、その相談の金額は使う予定のお金になり、やりくりの残りから引かれる（[今月のやりくり](budget.md) を参照）。同じおうちで、複数の相談に同時にいいねしても、いいねがそろった順に 1 つずつやりくりの残りを判断する。

## 見送り

- 相談やおねがいは、いいねする人の 1 人が見送れば、見送りになる。必要ないいねが 2 つの相談でも同じである。
- 見送るときは、見送りの理由を 1 つ以上選ぶ。理由のほかに、補足のコメントを書ける。「その他」を選んだときは、コメントを必ず書く。
- 見送りの理由の選択肢は、相談とおねがいで別のものを使う。

### 相談の見送りの理由

| コード | 理由 |
|---|---|
| `over_budget` | 今月のやりくりをオーバーしている |
| `not_needed_now` | 今すぐには必要なさそう |
| `already_have` | 家にあるもので代用できる |
| `cheaper_alternative` | もっと安いものがありそう |
| `wait_for_better_timing` | セールや来月まで待った方がいい |
| `too_expensive` | 金額が高すぎる |
| `rarely_used` | 使う機会が少なそう |
| `discuss_together` | 家族で話し合ってから決めたい |
| `other` | その他 |

### おねがいの見送りの理由

| コード | 理由 |
|---|---|
| `wallet_cannot_cover` | おうちのおさいふが足りなくなりそう |
| `too_big_change` | 変える幅が大きすぎる |
| `not_the_right_time` | 今はそのタイミングではなさそう |
| `need_more_detail` | もう少し詳しく聞かせてほしい |
| `discuss_together` | 家族で話し合ってから決めたい |
| `other` | その他 |
