# 今月のやりくり

用語は [ユビキタス言語](README.md#ユビキタス言語) に従う。

## 今月のやりくり

今月のやりくりは、1 か月に使ってよいお金の枠である。おうちのおさいふ（おうちが実際に持っているお金）とは別のもので、計画を表す。

- 今月のやりくりは、おうちのお金で決める。
- 毎月同じ金額で始まり、余っても翌月に繰り越さない。
- 「今月」は、おうちの時間で、毎月 1 日の 0 時から月の終わりまでとする。
- 今月のやりくりは、0 円以上の金額にする。0 円にすると、やりくりの残りが最初から 0 円以下になるので、すべての相談にいいねが 2 つ必要になる。

### 今月のやりくりを変える

- 今月のやりくりを変えるには、おねがいを出し、いいねをもらう。いいねの決まり方は [いいね](like.md) に従う。
- 増やすときも減らすときも、いいねがそろった瞬間から、今月の分も含めて新しい金額になる。
- 今月使ったお金が新しい金額を超える場合も、減らすことはできる。その場合は、やりくりオーバーになる。
- 今月のやりくりを変えても、すでに決まった必要ないいねの数や、確保された使う予定のお金は変わらない。

### 過去の月のやりくり

過去の月のやりくりは、その月の最後に有効だった金額とする。月の途中で変えた経緯は、おねがいの記録から辿れる。

## やりくりの残り

やりくりの残りは、次のように求める。

    やりくりの残り = 今月のやりくり − 今月使ったお金 − 使う予定のお金

やりくりの残りは、マイナスになることがある。

### 今月使ったお金

今月使ったお金は、いいねがそろった月が今月である相談のうち、買ったよ報告をした買い物の金額の合計である。翌月の 7 日までに報告された先月分の買い物は、先月の使ったお金に入る。

- おさいふから払った買い物も、たてかえで買った買い物も含む。
- たてかえのおかえしは、すでに今月使ったお金に含まれている買い物の代金を返すものなので、含めない。
- おさいふにいれる、おさいふからだすは、買い物ではないので含めない。

### 使う予定のお金

使う予定のお金は、いいね済みで、まだ買われていない相談の金額の合計である。

| できごと | 使う予定のお金 |
|---|---|
| 相談に必要ないいねがそろう | 相談した金額を確保する |
| 買ったよ報告をする | 確保をやめ、買った金額をいいねがそろった月の使ったお金に加える |
| とりやめになる | 確保をやめる |
| 時間切れになる | 確保をやめる |

使う予定のお金は、いいねがそろった月のものとして確保される。翌月の 7 日までに報告されなかった相談は時間切れになり、確保をやめる。いずれの場合も、使う予定のお金が翌月のやりくりの残りから引かれることはない。

相談した金額より安く買った場合は、確保していた金額との差が、やりくりの残りに戻る。

## サイン

次の状態になったら、家族にサインを出す。サインは、今月のやりくり、台帳の記録、今の時刻から、いつでも判断できる。

| サイン | 状態 |
|---|---|
| やりくりオーバー | 今月使ったお金が、今月のやりくりを超えている |
| おさいふピンチ | やりくりの残りが、おうちのおさいふのお金を超えている |

- やりくりオーバーのときは、やりくりの残りがマイナスなので、それ以降の相談はすべて、やりくりの残りを超える相談として、いいねが 2 つ必要になる（[いいね](like.md) を参照）。
- おさいふピンチは、今月のやりくりを最後まで使うと、おうちのおさいふのお金が足りなくなることを表す。おさいふピンチのあいだは、サインを出し続ける。

## 例

今月のやりくりが 100,000 円、おうちのおさいふに 150,000 円あるとする。

| できごと | 今月使ったお金 | 使う予定のお金 | やりくりの残り | おうちのおさいふ |
|---|---|---|---|---|
| 月のはじめ | 0 | 0 | 100,000 | 150,000 |
| 30,000 円の相談に、いいねがそろう | 0 | 30,000 | 70,000 | 150,000 |
| おさいふから 28,000 円で買う | 28,000 | 0 | 72,000 | 122,000 |
| 今月のやりくりを 20,000 円に減らす | 28,000 | 0 | −8,000 | 122,000 |

最後の行では、今月使ったお金が今月のやりくりを超えているので、やりくりオーバーのサインが出る。
