# おうちのおさいふ

用語は [ユビキタス言語](README.md#ユビキタス言語) に従う。

## おうちのおさいふ

おうちのおさいふは、おうちが実際に持っているお金である。今月のやりくり（使ってよいお金の枠）とは別のもので、事実を表す。

- おうちのおさいふのお金は、台帳の記録から求める。保存はしない。
- おうちのおさいふのお金は、マイナスになることがある。たてかえのおかえしなど、すでに起きたお金の動きは、おさいふのお金が足りなくても記録するからである。
- おうちのおさいふのお金がマイナスのあいだは、おさいふからっぽのサインを出す（[今月のやりくり](budget.md#サイン) を参照）。

### おさいふにいれる

- おさいふ係は、いいねなしで、おうちのおさいふにお金をいれられる。
- いれる金額は、おうちのお金で、0 より大きい金額にする。

### おさいふからだす

- おうちのおさいふのお金を、おうちの外に戻す（貯金に移すなど）には、おさいふ係がおねがいを出し、いいねをもらう。いいねの決まり方は [いいね](like.md) に従う。
- だす金額は、0 より大きく、おうちのおさいふのお金以下にする。
- いいねがそろったときに、おさいふからだしたことを記録する。

### おさいふから払う

- 買ったよ報告で、払い方を「おさいふから払う」にすると、買った金額がおうちのおさいふから払われたことを記録する（[相談](consultation.md) を参照）。

## たてかえとおかえし

### たてかえ

- 買ったよ報告で、払い方を「たてかえ」にすると、相談した家族が自分のお金で払ったことを記録する。
- たてかえた金額は、おかえし待ちのお金になる。おかえし待ちのお金は、おうちがその家族に返すべきお金である。

### たてかえのおかえし

- おさいふ係は、いいねなしで、たてかえのおかえしができる。
- おかえしは、家族ごとに、たてかえで買った複数の買い物をまとめてできる。
- 1 つの買い物は、全額をおかえしする。一部だけをおかえしすることはできない。
- おかえしすると、おかえしした買い物の相談は、おかえし済みになる。
- おかえしは、実際にお金を渡した事実の記録である。おうちのおさいふのお金がマイナスになる場合も、記録する。
- おかえし待ちのお金が残っている家族は、おうちから外せない（[おうちと家族](household.md) を参照）。

## つかいみち

つかいみちは、お金を何に使ったかの分類である。相談するときに 1 つ選ぶ。

### アプリが用意したつかいみち

アプリが用意したつかいみちは、おうちで名前を変えることも、しまうことも、消すこともできない。

| コード | つかいみち |
|---|---|
| `food` | 食べもの |
| `daily_goods` | 日用品 |
| `clothing` | 服 |
| `transport` | 交通 |
| `health` | 健康・医療 |
| `education` | 学び |
| `hobby` | 趣味・あそび |
| `social` | おつきあい |
| `home` | 住まい |
| `other` | その他 |

### おうちで追加したつかいみち

- おうちで、つかいみちを追加できる。
- 追加したつかいみちは、名前を変えられる。名前を変えると、過去の記録も新しい名前で表示される。
- 追加したつかいみちは、しまえる。しまったつかいみちは、今後の相談では選べないが、過去の記録からは見える。
- 一度も相談や台帳の記録で使われていないつかいみちは、消せる。

## 内部の仕組み：台帳の記録

ここからは、アプリの内部の仕組みである。家族が目にすることはない。台帳の考え方は ADR-0005、保存の形式は ADR-0007 に従う。

### 勘定

| 勘定 | 意味 |
|---|---|
| おさいふ | おうちのおさいふのお金 |
| おかえし待ち | おうちが家族に返すべきお金。家族ごとに持つ |
| 支出 | 使われたお金 |
| 拠出 | おうちの外から入ってきたお金、おうちの外に戻したお金 |
| 両替 | 通貨の両替で移ったお金（MVP では使わない） |

すべての勘定は、通貨を持つ。

### 移動

お金の動きは、「どの勘定から、どの勘定へ、いくら」という移動として記録する。移動の金額は、常に 0 より大きい。

| お金の動き | 移動元 | 移動先 | つかいみち |
|---|---|---|---|
| おさいふにいれる | 拠出 | おさいふ | |
| おさいふからだす | おさいふ | 拠出 | |
| おさいふから払う | おさいふ | 支出 | 相談のつかいみち |
| たてかえ | おかえし待ち（相談した家族） | 支出 | 相談のつかいみち |
| たてかえのおかえし | おさいふ | おかえし待ち（おかえしを受けた家族） | |

- 勘定のお金は、その勘定が移動先になった金額の合計から、移動元になった金額の合計を引いて求める。
- おかえし待ちの勘定のお金がマイナスであることは、おうちがその家族にお金を返す必要があることを表す。
- 移動は、それを生じさせた相談やおねがいのイベント、またはおかえしを参照する。

## まだ決めていないこと

- おうちで追加したつかいみちの追加、名前を変える、しまう、消すことは、誰ができるか。
