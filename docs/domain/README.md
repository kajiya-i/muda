# ドメイン

このディレクトリには、Muda が何をするアプリケーションなのかを定めるドメインの仕様を置く。

技術や構造の選択の理由は `docs/adr/`、コードの書き方の規約は `docs/rules/` に置き、ここには家族のお金のルールと、それを表す言葉を書く。

- [いいね](like.md)

## ユビキタス言語

家族、開発者、コードが、同じ言葉で同じものを指すための共通の語彙を定める。

- 画面に表示する言葉と、コードの名前は、この用語集に従う。
- 業務のような堅い言葉（申請、承認、却下など）は使わない。コンセプトの「しくみは厳しく、見た目はかわいらしく」に沿い、家庭の中で使うやわらかい言葉にする。
- コードの名前は、やわらかさよりも、概念を正確に指すことを優先する。
- 家族が知る必要のない内部の仕組みは、ユビキタス言語に含めない（「内部の用語」を参照）。
- ここに書く家庭の言葉は日本語での表現である。ほかの言語では、同じ概念をその言語のやわらかい言葉で表す。

### おうちと家族

| 家庭の言葉 | コード | 意味 |
|---|---|---|
| おうち | `Household` | アプリを使う単位。おうちのおさいふ、今月のやりくり、どきどきラインを 1 つずつ持つ。1 人で使う場合も、1 人のおうちとして扱う。 |
| 家族 | `Member` | おうちに属する人。 |
| おさいふ係 | `Keeper` | おうちのお金の流れを把握し、いいねできる家族。続柄ではなく役割であり、誰がなってもよい。 |
| おうちのお金 | `HomeCurrency` | おうちで主に使う通貨。 |
| おうちの時間 | `HomeTimeZone` | おうちのある場所のタイムゾーン。「今月」の区切りは、おうちの時間で決める。 |
| 参加中 | `Active` | おうちに参加している家族のようす。 |
| 外れた | `Left` | おうちから外れた家族のようす。過去の記録からは見える。 |

### 相談といいね

| 家庭の言葉 | コード | 意味 |
|---|---|---|
| 相談 | `Consultation` | 何かを買う前に、家族にいいねをもらうために出すもの。 |
| 相談した金額 | `ConsultedAmount` | 相談のときに伝えた金額。家族がいいねした金額の上限になる。 |
| いいね | `Like` | おさいふ係が相談などに同意すること。SNS のいいねと違い、拘束力のある同意である。 |
| 必要ないいね | `RequiredLikes` | 相談などが認められるために必要ないいねの数。1 つか 2 つ。 |
| じぶんでいいね | `SelfLike` | おさいふ係が 1 人だけのおうちで、そのおさいふ係が自分の相談に自分でいいねすること。家族の誰からも見える形で記録する。 |
| どきどきライン | `ThrillLine` | 1 回の買い物の金額のめやす。これを超える相談には、いいねが 2 つ必要になる。 |
| 今回は見送り | `Pass` | おさいふ係が相談やおねがいに同意しないこと。1 人でも見送れば、その相談やおねがいは見送りになる。 |
| 見送りの理由 | `PassReason` | 見送るときに、用意された選択肢から 1 つ以上選ぶ理由。相談とおねがいで、選択肢が異なる。 |
| とりやめ | `Withdrawal` | 相談した家族が、自分の相談を取り下げること。 |
| 時間切れ | `Expiry` | いいねをもらった相談が、いいねをもらった月の終わりまでに買われなかったこと。 |
| 買ったよ報告 | `PurchaseReport` | いいねをもらった相談について、実際に買ったことと、買った金額を伝えること。買った金額は、相談した金額を超えられない。 |
| おねがい | `Proposal` | 今月のやりくりやどきどきラインを変えるなど、おうちの決まりやお金を変えるために、いいねをもらうもの。おさいふ係だけが出せる。 |

### 相談のようす

| 家庭の言葉 | コード | 意味 |
|---|---|---|
| したがき | `Draft` | 相談を書いている途中で、まだ家族に出していない。 |
| いいね待ち | `AwaitingLikes` | 家族に相談を出し、いいねを待っている。いいねが 2 つ必要な相談では、1 つ目のいいねをもらった途中の段階も含む。 |
| いいね済み | `Liked` | 必要ないいねがそろい、買うのを待っている。 |
| 見送り | `Passed` | 今回は見送りになった。 |
| とりやめ | `Withdrawn` | 相談した家族がとりやめた。 |
| 時間切れ | `Expired` | いいね済みのまま、月の終わりを過ぎた。 |
| 買ったよ | `Purchased` | 買ったよ報告が済んだ。 |
| おかえし済み | `Repaid` | たてかえで買った相談について、おかえしが済んだ。 |

### 今月のやりくり

| 家庭の言葉 | コード | 意味 |
|---|---|---|
| 今月のやりくり | `MonthlyBudget` | 1 か月に使ってよいお金の枠。毎月同じ金額で始まり、余っても翌月に繰り越さない。 |
| やりくりの残り | `RemainingBudget` | 今月のやりくりから、今月使ったお金と、使う予定のお金を引いた残り。マイナスになることがある。 |
| 使う予定のお金 | `ReservedAmount` | いいね済みで、まだ買われていない相談の金額。 |
| やりくりオーバー | `OverBudget` | 今月使ったお金が、今月のやりくりを超えている状態。 |
| おさいふピンチ | `WalletPinch` | やりくりの残りが、おうちのおさいふのお金を超えている状態。やりくりを最後まで使うと、お金が足りなくなる。 |

### おうちのおさいふ

| 家庭の言葉 | コード | 意味 |
|---|---|---|
| おうちのおさいふ | `HouseholdWallet` | おうちが実際に持っているお金。今月のやりくり（計画）とは別のもの。 |
| おさいふにいれる | `TopUp` | おうちのおさいふにお金を入れること。 |
| おさいふからだす | `TakeOut` | おうちのおさいふのお金を、おうちの外に戻すこと（貯金に移すなど）。 |
| おさいふから払う | `WalletPayment` | 買い物の代金を、おうちのおさいふから直接払うこと。 |
| たてかえ | `Advance` | 家族が自分のお金で買い物の代金を払うこと。あとでおかえしを受け取る。 |
| たてかえのおかえし | `Repayment` | たてかえた代金を、おうちのおさいふから家族に返すこと。 |
| つかいみち | `Purpose` | お金を何に使ったかの分類。アプリが用意したものと、おうちで追加したものがある。 |
| しまう | `Archive` | おうちで追加したつかいみちを、今後の相談で選べないようにすること。過去の記録からは見える。 |

## 内部の用語

次の言葉は、アプリの内部の仕組みを表すもので、家族が目にすることはない。コードでは技術的な名前のまま使い、画面には出さない。

| 用語 | コード | 意味 |
|---|---|---|
| 台帳 | `Ledger` | お金の動きの記録。ADR-0005 で定めた多通貨の複式の台帳。 |
| 勘定 | `Account` | 台帳でお金がある場所を表す単位（おうちのおさいふ、支出など）。 |
| 移動 | `Transfer` | 台帳で、ある勘定から別の勘定へお金が動いた記録。 |
| イベント | `Event` | 相談などのようすが変わった事実の記録。 |
