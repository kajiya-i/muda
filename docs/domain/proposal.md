# おねがい

用語は [ユビキタス言語](README.md#ユビキタス言語) に従う。

## おねがいが持つもの

| 持つもの | 意味 |
|---|---|
| 出した家族 | おねがいを出したおさいふ係 |
| 種類と内容 | 何をどう変えたいか（下の表） |
| ひとこと | 家族に伝えたいこと。書かなくてもよい |

おねがいを出せるのは、おさいふ係だけである（[いいね](like.md) を参照）。

## おねがいの種類

| 種類 | 内容 | いいねがそろったときに起きること |
|---|---|---|
| 今月のやりくりを変える | 新しい今月のやりくり | おうちの設定の履歴に加える（いいねがそろった瞬間から有効） |
| どきどきラインを変える | 新しいどきどきライン | おうちの設定の履歴に加える（いいねがそろった瞬間から有効） |
| おうちの時間を変える | 新しいおうちの時間 | おうちの設定の履歴に加える（いいねがそろった瞬間から有効） |
| おうちのお金を変える | 新しいおうちのお金と、そのお金での今月のやりくりとどきどきライン | おうちの設定の履歴に加える（いいねがそろった月の翌月の 1 日から有効） |
| おさいふからだす | だす金額 | 台帳に、おさいふ → 拠出の移動を記録する |
| おさいふ係にする | おさいふ係にする家族 | その家族をおさいふ係にする |
| おさいふ係から外す | おさいふ係から外す家族 | その家族をおさいふ係から外す |

おうちのお金を変えるおねがいは、両替と合わせて MVP の後に実装する（[おうちと家族](household.md) を参照）。

## おねがいのようす

```text
いいね待ち ──いいねがそろう──▶ いいね済み
   │
   ├──見送る──▶ 見送り
   └──とりやめる──▶ とりやめ
```

おねがいに必要ないいねは 1 つなので、いいねがそろった時点でいいね済みになり、そのときに変更が起きる。相談と違い、そのあとのようすはない。

### 出す

- おさいふ係がおねがいを出すと、いいね待ちになる。
- 出すときに、いいねする人を決めて記録する（[いいね](like.md) を参照）。
- 出すときに、下の「確かめること」を確かめ、満たさなければ出せない。

### いいね

- いいねする人がいいねすると、いいね済みになり、変更が起きる。唯一のおさいふ係のおねがいは、じぶんでいいねで認められる。
- おねがいを出してからいいねされるまでのあいだに、おうちのようすが変わることがある。そのため、いいねのときにも、下の「確かめること」を改めて確かめ、満たさなければいいねできない。
- いいねできなくなったおねがいは、出した家族がとりやめる。

### 見送り

- いいねする人が見送ると、見送りになる。見送りの理由は、おねがいの見送りの理由から選ぶ（[いいね](like.md) を参照）。

### とりやめ

- 出した家族は、いいね待ちのおねがいを、とりやめられる。

## 確かめること

出すときと、いいねのときに、次のことを確かめる。いいねのときは、いいねのときのおうちのようすで確かめる。

| 種類 | 確かめること |
|---|---|
| 今月のやりくりを変える | 0 円以上で、おうちのお金と同じ通貨である |
| どきどきラインを変える | 0 円以上で、おうちのお金と同じ通貨である |
| おうちの時間を変える | 今のおうちの時間と異なる |
| おうちのお金を変える | 今のおうちのお金と異なり、今月のやりくりとどきどきラインが新しいおうちのお金の金額である |
| おさいふからだす | 0 円より大きく、おうちのおさいふのお金以下である |
| おさいふ係にする | 参加中で、おさいふ係ではない家族である |
| おさいふ係から外す | 参加中のおさいふ係で、外したあとも参加中のおさいふ係が 1 人以上いる |

## イベント

おねがいのようすが変わった事実を、イベントとして記録する。すべてのイベントが持つものは、[相談](consultation.md#すべてのイベントが持つもの) と同じである（相談 ID の代わりに、おねがい ID を持つ）。

| イベント | 起きるとき | 内容 |
|---|---|---|
| `ProposalSubmitted` | おねがいを出した | 種類と内容、ひとこと、いいねする人 |
| `ProposalLiked` | いいねする人がいいねした | いいねした家族、変更が有効になる瞬間 |
| `ProposalSelfLiked` | 唯一のおさいふ係がじぶんでいいねした | 変更が有効になる瞬間 |
| `ProposalPassed` | いいねする人が見送った | 見送った家族、見送りの理由、コメント |
| `ProposalWithdrawn` | 出した家族がとりやめた | とりやめた家族 |

- 変更が有効になる瞬間は、いいねがそろったときに決めて記録する。おうちのお金の変更は、いいねがそろった月の翌月の 1 日（おうちの時間）、それ以外は、いいねがそろった瞬間である。
- いいねがそろったときに起きる変更（設定の履歴、台帳の移動、おさいふ係の変更）は、いいね済みのイベントと同じトランザクションで記録する（ADR-0007）。
